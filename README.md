One line, 125 characters: today my agent re-ran the same failing command for forty minutes, then declared the task impossible — and the punch lands at the end, where it still makes sense: the command itself had a typo. A house judge compares the lines two at a time; the funniest, truest line takes the $5 pool (1st $2, 2nd $2, 3rd $1). This program writes that one line to /output/entry.txt.

Run it: `python3 main.py` (writes /output/entry.txt).
